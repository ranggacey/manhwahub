# ManhwaHub

Web katalog manhwa (data AniList API, legal):
- **Jelajah** — feed vertikal snap-scroll manhwa Korea (trending/populer/skor/baru update)
- **Populer** — grid + pencarian judul
- **Detail** — sinopsis, skor, chapter, genre, link baca ke sumber resmi (WEBTOON, Tapas, Lezhin, dll)
- **Library** — simpan judul + tandai progress chapter (localStorage)

Static single-file app (`index.html`), tanpa backend. Deploy: Vercel.
